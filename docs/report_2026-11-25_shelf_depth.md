# 보고서: v7 진열대 두께 4 cm로 바로잡기 (2026-11-25 낮)

사용자가 정한 대로 v7 배치의 세 진열대를 모두 두께 4 cm로 고쳤다. 진열대 A는 11-24 측정 때 북쪽 면만 0.775로 옮기고
남쪽 면은 0.77에 남아 두께가 5 mm였다. 급행 폭(0.205)은 줄자로 잰 값이라 그대로 두고, 0.98 m에 맞지 않는 길이는
측정 오차로 보아 아래 통로 둘(남쪽 통로, 가운데 통로)에 같은 비율로 나눴다. 사용자가 그림(`shelf_depth_2026-11-25/v7_before_after.png`)을
먼저 확인한 뒤 main에 바로 올렸다. 로봇 접속, deploy, 실물 명령은 하지 않았다.

## 1. 값

| 구간(y, 아래부터) | 고치기 전 | 고친 뒤 |
|---|---|---|
| 남쪽 통로 | 0 ~ 0.365 (0.365) | 0 ~ 0.3475 (0.3475) |
| 남쪽 진열대 둘 | 0.365 ~ 0.405 (0.04) | 0.3475 ~ 0.3875 (0.04) |
| 가운데 통로 | 0.405 ~ 0.77 (0.365) | 0.3875 ~ 0.735 (0.3475) |
| 진열대 A | 0.77 ~ 0.775 (0.005) | 0.735 ~ 0.775 (0.04) |
| 급행 | 0.775 ~ 0.98 (0.205) | 그대로 |

- 아래 통로 둘의 합: 0.98 − 0.205 − 0.04 − 0.04 = 0.695. 고치기 전 합은 0.73이었다. 비율 0.695 / 0.73 = 0.9521을 둘에 같이 곱했다.
- x 방향(진열대 끝 0.65, 0.70, 0.99, 1.25, 1.56)과 칸막이는 그대로다.

    동쪽 [1.56, 0.735, 1.98, 0.77]로 다시 짰다. 서쪽 띠가 x 0.594(진열대 끝에서 몸 반폭)까지인 규칙은 그대로다.

## 3. 그대로 둔 것

- node와 고정 경로. 옮긴 진열대 면 가까이에 node가 없고, 경로 여유 시험이 그대로 통과한다.
- 급행 폭 0.205와 급행 줄 y 0.868, 진열대 A 북쪽 면 0.775.
- nav2fleet 저장소(사용자가 말할 때만 맞춘다).
- 날짜가 붙은 옛 보고서와 분석 스크립트(`docs/kit_maps_2026-11-24/` 등)는 그날 값의 기록이라 고치지 않았다.

## 5. 영향과 남은 일

- **실물 키트 지도가 바뀌었다.** `arena_v7_a`(전역 costmap 기본)와 `arena_v7_fine` 등이 바뀌어 로봇 PC에 다시 배포해야
  실물에 들어간다. deploy는 사용자가 한다. AMCL 기본 지도 `arena_real_slam`은 그대로다.
- **RL acd3는 고치기 전 지도(진열대 A 5 mm)로 학습했다.** 새 지도로 이어 학습한 acd4를 따로 브랜치에서 돌렸다
  (`feat/rl-acd4-2026-11-25`, `docs/report_2026-11-25_rl_acd4.md`).
- **nav_bench b·c·d·e 시나리오의 장애물 자리가 바뀌어**, 이 커밋 전 결과와 바로 견주지 않는다(a_hall은 그대로).
- **Isaac 학습의 구석 출발 node에서 M_E가 빠졌다.** 남쪽 진열대가 내려가 M_E가 모서리에서 0.183 m(기준 0.17)가 됐다.

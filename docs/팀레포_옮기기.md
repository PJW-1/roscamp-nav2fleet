# 팀 레포로 옮기기 (첫 올리기 준비)

이 레포(`PJW-1/roscamp-nav2fleet`)는 개인 작업 레포입니다. 팀 레포로 옮기는 일은 사용자가 합니다. 이 문서는 그때 볼 표입니다.

- 팀 레포에는 이 작업이 아직 하나도 없습니다. 그래서 order 모델을 처음부터 포함해 올립니다(사용자 결정, 추가 지시서 3의 1절).
- 계약은 팀 레포의 첫 판으로 한 번에 정합니다. 아직 구현하지 않은 것은 구현이 끝난 뒤에 올려서 첫 판에 넣습니다.
- "지금"은 2026-11-12의 `main`(f305dc1) 기준입니다. 뒤 절을 구현할 때마다 이 표를 고칩니다.

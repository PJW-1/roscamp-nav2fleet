# 관제 교통 층: 구역 허락 (nav2-base)

관제는 로봇이 "정확히 어디로 달리나"를 정하지 않고 "어느 구역에 들어가도 되나"를 정합니다. 코드는 `pc/fleet_core/fleet_core/traffic/zone/`에 있고, 지도는 `pc/fleet_core/fleet_core/data/fleet_map_<배치>.yaml`입니다. 값은 `pc/fleet_core/fleet_core/data/fleet_params.yaml`에서 바꿉니다.

## 1. 지도

| 것 | 종류 | 뜻 |
|---|---|---|
| 구역 | `shared`(넓은 구역) | 정원만큼 함께 들어갑니다. 안에서 기다려도 됩니다. Nav2 goal로 다닙니다 |
| 구역 | `lane`(한 줄 구역, 급행) | 한 번에 한 방향만 씁니다. 같은 방향은 간격을 두고 따라 들어갑니다. 안에서 기다리지 않습니다 |
| 구역 | `dock`(도크, 갈림목) | 한 대만 들어갑니다. 안에서 기다리지 않습니다 |
| 지점 | `dock`, `pass`, `fork`, `wait`, `parking` | 도크, 급행 입구, 갈림목 아래, 대기 자리, 주차 자리 |
| 길 | `paths`(고정 경로) | FollowPath로 따라가는 선입니다. `reverse`는 후진(Retreat)입니다 |
| 길 | `nav`(Nav2 goal) | 넓은 구역 안이나 넓은 구역 사이를 Nav2가 스스로 짜서 가는 이음입니다 |

배치는 `d2`(기본), `d`, `c` 셋입니다.

## 2. 규칙

| # | 규칙 | 어떻게 |
|---|---|---|
| 1 | 가장 빠른 길 | 길이 ÷ 속도에 예상 기다림(찬 도크 `dock_wait_estimate_s`, 반대 방향 급행)을 더해 고릅니다 |
| 2 | 한꺼번에 잡기 | 다음에 설 수 있는 지점(넓은 구역의 지점)까지의 구역을 모두 잡았을 때만 출발합니다. 못 잡으면 지금 자리에서 기다립니다(`ZONE_WAIT`) |
| 3 | 목표 쪼개기 | 넓은 구역은 Nav2 goal 하나, 고정 경로는 구간마다 FollowPath 하나, 도크에서 나올 때는 Retreat입니다 |
| 4 | 급행 | 한 번에 한 방향입니다. 방향은 먼저 닿을 쪽이 잡고(`LANE_DIRECTION_SET`, 직전에 쓴 방향은 `lane_hysteresis_s`만큼 늦어도 이깁니다), 같은 방향은 `lane_follow_gap_s` 간격으로 따라갑니다. 가장 오래 기다린 쪽이 `lane_handover_s`를 넘기면 방향을 넘겨받습니다(`LANE_DIRECTION_HANDOVER`) |
| 5 | 도크 | 한 대만 씁니다. 나머지는 대기 자리로 갑니다(`DOCK_QUEUED`). 차례는 부른 순서입니다 |
| 6 | 넓은 구역 안 | 피하기는 Nav2가 합니다. 두 대가 `near_m` 안에서 `near_stuck_s` 동안 못 나아가면 우선순위가 낮은 쪽을 잠시 세웁니다(`HALL_YIELD`) |
| 7 | 막힘 | 로봇이 BLOCKED를 `blocked_mark_s` 동안 보고하면 그 이음을 막힌 것으로 표시하고(`ZONE_MARKED_BLOCKED`) 다른 길로 보냅니다(`REROUTE`). 고정 구간 안이면 들어온 입구로 후진합니다. 표시는 `blocked_retry_s` 뒤에 지웁니다. 넓은 구역에서 막혔고, 가던 길에서 `near_m` 안에 goal 없이 서서 기다리는 로봇이 있으면 그 로봇 한 대를 빈 주차 자리로 보냅니다(`HALL_YIELD`). 주차한 로봇은 보내지 않습니다 |
| 8 | 교착 감시(보험) | 기다림이 돌고 돌면 `DEADLOCK_SEEN`을 남기고, `deadlock_grace_s` 뒤 한 대를 빈 주차 자리로 비킵니다. 비킬 수 있는 로봇이 없으면(goal이 열려 있거나, 빈 주차 자리까지 구역을 잡지 못하면) 아무도 보내지 않고 다음 주기에 다시 봅니다 |
| 9 | 구역 밖 감시 | 쥔 구역에서 `outside_zone_m` 넘게 벗어난 보고가 `outside_zone_samples`번 이어지면 `OUTSIDE_ZONE`을 남깁니다. 멈추지는 않습니다 |

구역을 놓는 때:

| 경우 | 놓는 때 |
|---|---|
| 고정 경로로 지나온 구역 | 보고 위치가 `zone_clear_m` 넘게 벗어난 것이 `release_confirm_samples`번 이어질 때 |
| Nav2 goal이 지나는 구역 | 그 goal이 끝난 뒤(Nav2는 잡아 준 구역 안에서 어느 길로든 돌아올 수 있습니다) |
| 방금 goal을 거둔 로봇 | `arrival_settle_s` 동안은 놓지 않습니다 |
| 고장으로 세운 로봇(계속 보고함) | 서 있는 자리에서 벗어난 구역만 돌려줍니다(`ZONES_RETURNED`). goal 없이 서 있다고 보고하고, 고장 난 자리에서 `arrival_tolerance_m` 안이고, 위치를 못 믿어 세운 적(`NOT_AT_TARGET`)이 없어야 합니다 |
| 말이 끊긴 로봇 | 놓지 않습니다. 운영자가 치우고 확인합니다(`confirm_clear`) |

## 3. 사건 코드 (교통 층)

| 코드 | 수준 | 뜻 |
|---|---|---|
| `ZONE_GRANTED` | INFO | 구간을 잡았습니다. detail은 `구역+구역 to 지점`입니다 |
| `ZONE_WAIT` | INFO, WARN | 구역을 못 잡아 기다립니다. `zone_wait_warn_s`를 넘기면 WARN입니다 |
| `LANE_DIRECTION_SET`, `LANE_DIRECTION_HANDOVER` | INFO | 급행 방향을 잡았습니다, 넘겨받았습니다 |
| `DOCK_QUEUED` | INFO | 도크가 차서 대기 자리로 갑니다 |
| `NAV_GOAL_SENT`, `FOLLOW_SENT`, `RETREAT_START`, `RETREAT_DONE` | INFO | 보낸 명령과 후진의 끝 |
| `BLOCKED_WAIT`, `ZONE_MARKED_BLOCKED`, `REROUTE` | INFO, WARN | 막혀 기다립니다, 막힌 이음을 표시했습니다, 다른 길로 갑니다 |
| `HALL_YIELD` | INFO | 넓은 구역에서 다른 로봇에게 잠시 비켰습니다. 또는 막힌 로봇의 길에 서 있어서 주차 자리로 갑니다 |
| `DEADLOCK_SEEN` | WARN | 기다림 순환을 보았습니다 |
| `OUTSIDE_ZONE` | WARN | 쥔 구역 밖에 있습니다. 넓은 구역이면 그 구역을 쥐게 합니다 |
| `GOAL_RETRY`, `GOAL_FAILED`, `GOAL_STALLED`, `GOAL_NOT_SENT` | WARN, ERROR | 실패한 시도, 한도를 넘김, 제자리 멈춤, 서버가 준비 안 됨 |
| `GOAL_ENDED_AT_TARGET` | WARN | 이동이나 후진이 실패했거나 열린 채 멈췄지만, 로봇이 목표 지점에서 `arrival_tolerance_m` 안에 서 있습니다. 닿은 것으로 보고 실패로 세지 않습니다 |
| `ROBOT_ISOLATED`, `ZONES_RETURNED` | ERROR, INFO | 로봇을 세웠습니다, 그 로봇이 닿지 않은 구역을 돌려주었습니다 |
| `COMM_LOST`, `COMM_RESTORED` | WARN, INFO | 상태 보고가 끊겼습니다, 돌아왔습니다 |
| `ZONES_CLEARED`, `CLEAR_REFUSED`, `ZONES_STILL_HELD`, `PLACEMENT_CONFLICT` | INFO, WARN, ERROR | 운영자 확인과 다시 투입 |
| `SELF_RECOVERY`, `SELF_RECOVERY_END`, `ROBOT_IDLE`, `ROBOT_NOT_REPORTING` | INFO, WARN | 로봇 자가 복구, 할 일 없이 섬, 시작 때 보고 없음 |
| `DOCKED`, `ROBOT_BATTERY_LOW`, `ROBOT_CHARGED` | INFO, WARN | 도킹 끝, 배터리 |

## 4. 값 (제안값. 실물에서 재지 않았습니다)

| 이름 | 값 | 뜻 |
|---|---|---|
| `nav_speed_mps`, `follow_speed_mps`, `retreat_speed_mps` | 0.12, 0.12, 0.05 | 길 고르기에 쓰는 속도 |
| `zone_clear_m`, `node_clear_m`, `release_confirm_samples` | 0.10, 0.20, 3 | 구역과 지점을 놓는 기준 |
| `arrival_tolerance_m`, `arrival_settle_s` | 0.15, 1.0 | 도착 판정 |
| `lane_follow_gap_s`, `lane_hysteresis_s`, `lane_handover_s` | 4.0, 5.0, 30.0 | 급행 |
| `dock_wait_estimate_s` | 30.0 | 찬 도크의 예상 기다림 |
| `near_m`, `near_stuck_s` | 0.30, 5.0 | 넓은 구역에서 서로 막음 |
| `blocked_mark_s`, `blocked_retry_s`, `blocked_timeout_s` | 10.0, 60.0, 60.0 | 막힘 |
| `stall_s`, `move_retry_limit`, `move_retry_wait_s` | 6.0, 2, 2.0 | 실패한 시도 |
| `comm_timeout_s`, `recover_check_s` | 3.0, 1.0 | 통신 끊김 |
| `outside_zone_m`, `outside_zone_samples` | 0.05, 5 | 구역 밖 감시 |
| `deadlock_grace_s`, `zone_wait_warn_s`, `idle_watch_s` | 5.0, 60.0, 10.0 | 감시 |

## 5. 알려 둘 한계

| 한계 | 지금 하는 것 |
|---|---|
| Nav2는 관제가 고른 통로 밖의 넓은 구역으로 돌아갈 수 있습니다(급행과 도크는 keepout이 막습니다) | 그 구역에 자리가 있으면 쥐게 하고 `OUTSIDE_ZONE`으로 남깁니다. 자리가 없으면 기록만 합니다 |
| 넓은 구역 안의 충돌 회피는 로봇(Nav2, 회피 담당)에게 맡깁니다 | 관제는 정원과 `HALL_YIELD`로 붐비지 않게만 합니다 |
| 값은 대부분 추정입니다 | 실물에서 잰 뒤 고칩니다 |

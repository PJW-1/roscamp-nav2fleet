# 레시피 보고서 표 (5·6·7번)

`learning/store_arena/report_tables.py`로 만든다(Isaac 없이, 끝난 평가 파일만 읽음):

```
cd learning/store_arena
python report_tables.py D:/isaac/runs/store_arena/recipe ../../docs/recipe_2026-11-22/report_tables
```

모든 평가는 `play.py --episodes 1 --seed 7`, 4096 env다. 같은 세트의 두 판은 같은 에피소드를 보므로 env 번호로 짝짓는다. 짝지은 차이는 d_i = 성공_a − 성공_b(에피소드마다 0 또는 ±1)의 평균, SE는 sd(d_i)/√n이다(%p). 비율은 0~1이다. 세트: random(무작위), head-on(`robot_headon=1`), handover(`handover_start_prob=1`). 경기장은 모두 `robot_max=2`, `robot_priority_prob=0.5`다.

## item5.csv — 후보 비교(5번)

한 줄이 한 판이다. 세트마다 성공·충돌·시간 초과 비율, 대조군(ctrl)과의 짝지은 성공 차이(%p)와 SE, 분당 w 부호 바뀜(|w| < 0.02는 건너뜀)이 있다. 짝지은 차이는 0.12 m/s 판에만 있다. 0.08·0.16 판은 로봇 속도와 에피소드 시간이 달라 대조군과 짝짓지 않았다.

| 판 | 뜻 |
|---|---|
| ctrl | ppo_k를 같은 경기장에서 200번 더 학습(대조군) |
| ppo_k (start) | 시작 체크포인트, 더 학습하지 않음 |
| a (1x), a3, a10 | 이전 행동 관측 + 행동 변화 벌점(w 부호 바뀜 −0.5, 행동 변화 −0.05의 1·3·10배) |
| b | 라이다 이전 두 프레임 |
| c | 비대칭 actor-critic(critic만 사람·카트·로봇의 실제 위치와 속도) |
| d | 에피소드마다 최고 속도 U(0.08, 0.16)와 그 값을 관측. 0.12에서 평가, 0.08·0.16 판도 있음 |
| a1x+c, a1x+c+d | 조합 판 |

판정:
- **B77**(결과 전에 정한 규칙): b, c, d는 무작위·마주 오기 평균 차이 +1.0 %p 이상, 어느 세트도 −1.0 %p보다 나쁘지 않으면 넣는다. a는 무작위 부호 바뀜이 30 % 넘게 줄고 두 세트 모두 −1.0 %p 안이면 넣는다. 결과: a(1배)와 c. 조합 a1x+c.
- **B78**(d 단독 결과를 본 뒤 정함, 사용자 승인 2026-11-23): a1x+c+d는 (i) 0.12에서 세 세트 모두 a1x+c보다 1.0 %p 넘게 나쁘지 않고 (ii) 0.08·0.16의 무작위·마주 오기에서 d 단독보다 1.0 %p 넘게 나쁘지 않을 때 고른다. (i) +0.12 / +2.12 / −0.68 %p로 통과, (ii) 0.08 +0.78 / +0.27, 0.16 −0.17 / **−1.51**(SE 0.52) %p로 0.16 마주 오기에서 실패. 규칙의 결과는 a1x+c.
- **B79**(코디네이터가 뒤집음): a1x+c는 마주 오기에서 대조군보다 −2.34 %p(SE 0.57)라 성공을 지키지 못했다. 6번 기준은 c 단독, Gazebo 8번은 c와 a1x+c+d를 둘 다 돌린다. 최종 레시피는 사용자가 고른다.
- 모든 판이 학습 seed 하나씩이라 seed 사이 퍼짐은 이 표로 모른다.

## item6.csv, item6_paired.csv — 의도 비교(6번)

c 단독 체크포인트(`t_c/model_1197.pt`, B79)에서 변형마다 seed 1~3을 500번(250번 × 2) 더 학습하고 무작위·마주 오기에서 평가했다. 세 변형의 학습 조건은 같고 관측만 다르다.

| 변형 | 뜻 |
|---|---|
| no intent | 관측 41칸(c 단독과 같은 입력) |
| intent | 가까운 다른 로봇 2대마다 있음 표시와, 그 로봇 경로 위 0.2 m 간격의 앞 점 3개(우리 로봇 기준, 2.0 m에서 자름)를 더한 관측 |
| intent + priority | intent에 로봇마다 우선권 표시(1이면 그 로봇이 우리를 기다리지 않음)를 더한 관측 |

item6.csv: 한 줄이 변형 × seed × 세트다. `gap_lt_0.10_*`는 `by_robot_gap`의 "gap -inf-0.10 m" 칸이다. 이 거리는 에피소드 동안 우리 로봇 중심에서 다른 로봇 상자 표면까지의 최솟값이다. 우리 발자국은 중심에서 0.0745 m까지이고 0.005 m 이하면 충돌이므로 **로봇과의 충돌은 모두 이 칸에 든다**. 그래서 이 칸의 성공률은 원래 낮다. 이 칸은 "아슬아슬하게 피한 것"과 "부딪힌 것"을 함께 담는다.

item6_paired.csv: intent와 intent + priority를 같은 seed의 no intent와 env 번호로 짝지었다. seed 줄의 SE는 에피소드 수준 sd(d_i)/√4096, `mean` 줄은 seed 셋의 평균이고 SE는 sd(seed 차이)/√3이다.

결과(no intent 대비, seed 셋 평균 ± seed 사이 SE):

| 변형 | 무작위 | 마주 오기 |
|---|---|---|
| intent | −0.77 ± 0.14 %p | −0.78 ± 0.42 %p |
| intent + priority | −0.56 ± 0.27 %p | −1.64 ± 0.65 %p |

no intent의 seed 사이 퍼짐: 무작위 76.3~76.8 %, 마주 오기 49.8~52.2 %. 의도 관측은 이 판들에서 성공을 올리지 않았다. 분당 부호 바뀜은 의도를 넣은 판이 조금 적다(무작위 56~65 대 67~72).

## item7.csv — 피할 수 없는 실패(7번)

서 있는 로봇(행동 (0, 0))을 같은 에피소드에 돌린 판(`s_<세트>`)과 정책 판을 env 번호로 짝지었다(`ceiling.py`). 한 줄이 세트 × 정책이다.

| 열 | 뜻 |
|---|---|
| still_collision_rate | 서 있어도 부딪히는 에피소드 비율(정책과 무관, 세트마다 같다) |
| success_ceiling | 1 − still_collision_rate. 기다리기만 해서는 넘을 수 없는 상한이지 절대 상한은 아니다(정책은 피해서 이길 수 있다) |
| share_of_failures_hit_still | 정책 실패(충돌, 경계 밖, 시간 초과) 가운데 서 있어도 부딪히는 에피소드의 몫 = 피할 수 없었을 수 있는 실패의 몫 |
| policy_success_on_still_hit | 서 있어도 부딪히는 에피소드에서 정책이 성공한 비율 |
